  1. Tiny adventure

    AI creates the next scene. Choose a story path and keep the exact ending.

    Start with Haunted library and Silly. Three scenes, two choices, one story to keep.

  2. Activity finder

    AI suggests filters. Your app selects known catalog entries and maps their sample locations.

    Start with all filters set to Any. The sample map uses illustrative locations.

  3. Text remixer

    Review a rewrite, edit it, then choose Apply or Undo.

    Start with Friendly. Try changing the wording, applying the suggestion, and undoing.

  4. Sketch and Caption

    Draw something, ask AI what it sees, and keep your reviewed description.

    Start with a blank canvas or use Example sketch for a keyboard-accessible option.

  5. Timing and recovery lab

    Repeatable simulations show old responses, cancellation, and recovery. The scripted lab makes no AI calls.

    Three labeled simulations: late answers, Stop, and recovery. This lab needs no API key.

Real AI needs a local .env with your own key and the Node 22+ server. Without a key, you can still explore prepared examples and the deterministic resilience lab. Use node server.mjs from this folder, then browse to http://127.0.0.1:8787.

A loaded key confirms configuration, not successful AI responses. Test a request to confirm the provider is working. All prepared examples are explicitly labeled.

Alt+P reveals prepared examples on the feature pages. The activity finder map needs internet for ArcGIS and OpenStreetMap; manual catalog filtering still works if the map fails. GitHub: @cyatteau.
